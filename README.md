# AI_Agents
Repo to house a place to learn about making AI Agents ( ideally make anything , that is free !!) 

# Whats the goal?
1. Learn how to make an agent 
2. Learn how to give an agent memory
3. Learn how an agent can interact with other applications (MCP - Model Context Protocol)
4. Learn how to make differing agents: in terms of personality , and job role.
5. Any other bonus content that could be cool

# Whats the ideal perfect world
- The catch up in the AI game ( coming from Data Science wanting to scratch off the rust GEN ai wise ;)) 
- The ability to make agents for free, without having a financial constraint to learn and play.
- To make a household of agents like im a Master of the manor, a head butler and the underlings that report into the butler , with their own personalities :)
